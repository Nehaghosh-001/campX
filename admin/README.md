# CampusOrbit Master Admin Panel

Dedicated Control Center for the **Super Admin** of the Centralized Multi-College Placement Management System.

## Features & Capabilities
1. **Accreditation Document Verification Queue**: Inspect AICTE / UGC approval certificates uploaded by colleges, verify and approve institution accounts.
2. **Master Colleges Directory**: Manage all colleges, active tenant statuses, TPO contacts, and onboard new institutions.
3. **Student Talent Directory**: Global student directory with multi-branch filters, roll numbers, CGPA, backlogs, and detailed profile inspection modals.
4. **Recruiter & Corporate Partner Management**: Review and verify company accounts and active hiring drives.
5. **Campus Drives Monitor**: Audit all recruitment drives across universities, package CTC, eligibility rules, and applicants.
6. **Placement Records & CTC Audit**: Consolidated university placement offers, designations, and packages.
7. **System Health & Analytics**: Real-time platform metrics and multi-tenant security verification.

## Running the Admin Panel
```bash
cd admin
npm install
npm run dev
```
Port: `http://localhost:5174`
Default Credentials: `admin@gmail.com` / `admin@123` (or click 1-Click Instant Access)
